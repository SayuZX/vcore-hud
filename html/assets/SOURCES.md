# Bundled visual asset sources

These assets are local and require no runtime CDN requests.

## Poppins typeface

- Files: `Poppins-Regular.ttf` (400), `Poppins-Medium.ttf` (500), and `Poppins-SemiBold.ttf` (600).
- Source: [Google Fonts Poppins directory](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/poppins).
- Authors: The Poppins Project Authors; Indian Type Foundry, Jonny Pinhorn, and Ninad Kale.
- Copyright 2020 The Poppins Project Authors (https://github.com/itfoundry/Poppins).
- License: SIL Open Font License 1.1, included unmodified in `OFL-Poppins.txt`.
- The font files are unmodified copies from the source commit above.
